## 📚 Idea/Concepto 

La cohesión se refiere al grado en que los elementos de un módulo están fuertemente relacionados y trabajan juntos para cumplir una única responsabilidad bien definida. En ingeniería de software se busca alta cohesión, ya que favorece la ortogonalidad, reduce code smells como los cambios divergentes y complementa el principio de bajo acoplamiento para lograr sistemas más claros, mantenibles y fáciles de evolucionar.
